Containerized PostgreSQL Analytics Stack

Tech Stack: PostgreSQL | Docker Compose | pgAdmin | Advanced SQL (JSONB, GIN Indexes)

The Objective: To build a locally hosted, multi-container database architecture to securely store and analyze complex, unstructured gameplay data from the Space Cat Game.

The Solution: I orchestrated a Client-Server architecture using Docker Compose, deploying a PostgreSQL vault alongside a pgAdmin web interface on a private virtual network. I engineered an advanced relational schema utilizing UUIDs, Foreign Keys with cascading deletes, and a JSONB column optimized with a GIN index to handle highly flexible game session metadata.

Key Technical Features:

  • Container Orchestration: Linked isolated database and web dashboard containers over a custom Docker network without port conflicts using docker-compose.yml.
  • Advanced Data Modeling: Structured relational tables using UUIDs and Foreign Keys with ON DELETE CASCADE to enforce strict data integrity.
  • High-Performance JSONB: Implemented a GIN (Generalized Inverted Index) utilizing jsonb_path_ops for lightning-fast querying of unstructured, nested JSON run data (e.g., tracking collected items and defeated bosses).

Automated Multi-Node Infrastructure Provisioning

Tech Stack: Ansible | Docker | Windows Subsystem for Linux (WSL) | YAML | SSH

The Objective: To build a locally simulated cloud environment using Docker, managed entirely agentless via Ansible to demonstrate scalable Infrastructure-as-Code (IaC) configuration management.

The Solution: I architected a local testing environment that bypasses the need for remote cloud instances by containerizing Ubuntu servers. I engineered declarative YAML playbooks to connect over SSH, enforcing configuration idempotency, automating bare-metal server provisioning, and standardizing user access management across multiple nodes simultaneously.

Key Technical Features:

  • Infrastructure Automation: Built custom Docker images mapped to distinct local ports to simulate a multi-node cluster.
  • Idempotent Workflows: Developed Ansible playbooks using apt, user, and copy modules to ensure consistent, repeatable OS-level setups.
  • Agentless Orchestration: Executed configuration management over standard SSH protocols without installing tracking daemons on the target nodes.

Memory Card Game

The Memory Card Game is a fun and interactive game designed to test and improve your memory skills. The objective of the game is to match pairs of cards by flipping them over two at a time. If the cards match, they remain face up; if not, they are flipped back over.

The game features three difficulty levels: easy, medium, and hard. Each level offers a different number of cards to match. The easy level has 4 cards, the medium level has 16 cards, and the hard level has 36 cards.

The game features a timer that increases with the difficulty level,and a bonus score for correct cards streaks.

The game is built using c# and Windows Forms App (.NET Framework).
